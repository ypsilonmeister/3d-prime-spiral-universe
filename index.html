リーマン予想と素数（明示公式）

素数の並びの「ゆらぎ」を、ゼータ関数の零点の波でどこまで再現できるかを 3D 螺旋上に描いています。

零点数 N: 0 / 1000

1. 実測のゆらぎ ψ₁(x) − x²/2

素数（と素数べき）の分布から直接計算した、平均的な増加傾向 x²/2 からの「ずれ」です。中心の灰色らせんが基準線（ずれ 0）で、シアン線が実測値を表します。

2. ゼータ零点による再構成

リーマンゼータ関数の非自明な零点を低い方から N 個だけ重ねたオレンジのリボンです。N が大きいほど傾向として実測（シアン線）へ近づきますが、N を 1 つ増やすごとに必ず誤差が小さくなるとは限らず、局所的にも全体の指標でも増えることがあります。帯の色は残差が大きいほど赤くなり、シアン線との間を結ぶ白い残差 rung（横木）は実測と再構成の差を拡大表示した目印です。

3. RH を仮定した場合の誤差上限 ±B₁(x)

もしリーマン予想（RH）が正しいと仮定した場合に成り立つ理論上の誤差上限（Schoenfeld の上限、x ≥ 73.2）を、面ではなく紫の輪郭線（上下の境界線と等間隔リングの殻）で示しています。実測がこの輪郭の内側にあるのは表示範囲（x ≤ 320,000）での観測であり、リーマン予想の証明ではありません。
